# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What This Is

Personal website (aviva.gay) with an interactive pixel art guestbook. Users create 8x8 paintings from a 6-color palette, stored in a Cloudflare D1 database.

## Commands

All commands use `just` (task runner). The justfile prepends `./node_modules/.bin` to PATH so tools like `vinxi` and `wrangler` work directly.

```bash
just dev              # local dev server (vinxi dev)
just build            # production build (vinxi build)
just preview          # build then wrangler pages dev
just deploy           # build then wrangler pages deploy
just deploy-main      # deploy to production (main branch)
just test             # run vitest (excludes .direnv/**)
just test --run       # run tests once (no watch)
just typegen          # regenerate Wenv interface from wrangler.toml
just check            # tsc --noEmit --watch --skipLibCheck
```

## Architecture

**Framework:** SolidStart (SolidJS) with Cloudflare Pages preset (`app.config.ts`). File-based routing under `src/routes/`.

**Path alias:** `~/` maps to `./src/` (tsconfig paths).

**Key data flow:**
- `src/api/server.ts` — server RPCs (`"use server"` directive) for reading/writing paintings to D1
- `src/api/index.ts` — wraps RPCs as SolidJS `query()` and `action()` for client consumption
- `src/api/serverUtils.ts` — `useEvent()` helper that extracts Cloudflare bindings from the request, with wrangler platform proxy fallback in dev
- `src/api/ratelimit.ts` — GCRA-based rate limiter with pluggable backing store (D1 in prod)

**Cloudflare bindings:** The `Wenv` interface (in `worker-configuration.d.ts`, generated by `just typegen`) types the D1 database binding (`env.DB`) and config vars. Declared on `vinxi/http`'s `H3EventContext` in `src/global.d.ts`.

**Dev/prod mode:** `src/mode.ts` exports `IS_DEVELOPMENT`/`IS_PRODUCTION` booleans. Toggled to production by `just prodconfig` (sed replacement) before deploy — don't commit the change.

**Pixel system:** `src/pixelConfig.ts` defines the 8x8 grid (`WIDTH`), 6-color palette, and `DEPTH` (max color index). `src/components/Pixel.tsx` contains `Render` (canvas renderer), `Paint` (editor with palette), and `Gallery` (fetches and displays all paintings).

**Database:** Two tables defined in `src/schema.sql` — `Paintings` (blob data + author IP) and `Ratelimits` (GCRA timestamps).

**SSR considerations:** Gallery is loaded `clientOnly` on the index page to avoid FOUC from canvas painting in effects. The `Render` component uses `createDeferred` when `defer` prop is set. `src/rng.ts` stores a seed in search params for deterministic SSR/hydration.
